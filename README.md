# شاشة مواقيت الصلاة — مساجد سلطنة عُمان
Oman Mosque Prayer Display — offline-first PWA

شاشة عربية لمواقيت الصلاة والإقامة تعمل على تلفاز المسجد والحاسوب والهاتف، وتستمر في العمل دون إنترنت بعد التجهيز الأول.

Prepared by: Hani Al Ghatrifi

---

## 1. ما الذي يقدمه التطبيق

| المجال | الوصف |
|---|---|
| الشاشة الرئيسية | اسم المسجد (عربي/إنجليزي/شعار)، ساعة كبيرة بتوقيت مسقط، اليوم، التاريخ الهجري والميلادي، لوحة «أوقات الصلاة» ولوحة «الإقامة والضحى»، الصلاة القادمة والإقامة القادمة |
| العد التنازلي | يظهر قبل كل أذان وإقامة بـ 60 ثانية، محسوب من الطوابع الزمنية المطلقة (لا يتقدم ولا يتأخر) |
| الشاشة السوداء | تبدأ عند الإقامة (5 دقائق افتراضياً)، ثم الأذكار (5 دقائق، ذكر كل 60 ثانية)، ثم العودة تلقائياً |
| استثناء الهاتف | الهاتف لا يعرض الشاشة السوداء ولا الأذكار؛ يمكن تحديد نوع الجهاز يدوياً |
| الجمعة | إعداد مستقل: وقت البداية، الإقامة، مدة السكون، الإعلان، تسمية الصف، مظهر مميز؛ ويعود العرض العادي يوم السبت |
| الإقامة | تأخير بالدقائق أو وقت ثابت لكل صلاة، قواعد لأيام الأسبوع، استثناءات بتاريخ، وتجاوز من الجدول نفسه |
| الجدول | استيراد CSV/JSON (يومي/شهري/سنوي) مع تحقق كامل، تصدير، عرض يوم/شهر/سنة، تعديل يوم، استعادة الجدول السابق، طباعة شهر |
| الهجري | أم القرى المدمج في المتصفح + تعديل ±3 أيام (قابل للتوسيع) + خيار التغيير عند المغرب |
| دون إنترنت | Service Worker يحفظ كل الملفات والخطوط، وIndexedDB يحفظ الإعدادات والجدول والأذكار |
| الإدارة | 10 أقسام، رمز دخول اختياري، نسخ احتياطي واستعادة، صفحة تشخيص، محاكاة، سجل أحداث |

## 2. مصادر المواقيت الرسمية (نتيجة البحث)

- `mara.gov.om/arabic/calendar.html` و `awqafoman.om` **يمنعان الوصول الآلي** (robots)، ولم يُعثر على واجهة برمجية عامة أو ملفات تنزيل للمواقيت.
- المصدر الرسمي العملي: تطبيق الوزارة **«تقويم عُمان»** (عرض شهري للمواقيت) والتقويم المطبوع.
- لذلك المسار المعتمد: **نقل جدول الوزارة إلى CSV/JSON ثم استيراده** — راجع `docs/TIMETABLE-UPDATE.md`.
- لا يحتوي التطبيق على أي مواقيت رسمية جاهزة. تفاصيل وتصنيف البيانات في `docs/DATA-SOURCES.md`.

تصنيف البيانات الظاهر في الإدارة (وعلى الشاشة عند الحاجة):

| النوع | المعنى | يظهر على الشاشة |
|---|---|---|
| `official` | منقول من تقويم الوزارة بواسطة المشرف | لا شارة |
| `admin` | إدخال أو تعديل يدوي من المشرف | لا شارة |
| `calculated` | محسوب فلكياً على الجهاز — **غير رسمي** | شارة «مواقيت محسوبة» (قابلة للإخفاء) |
| `demo` | بيانات تجريبية للتطوير — **غير رسمية** | شارة «DEMO DATA» دائماً |

## 3. التشغيل محلياً

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # 53 اختباراً للمحرك والبيانات والتخزين
npm run build        # إنتاج dist/ مع Service Worker
npm run preview      # http://localhost:4173 (يدعم العمل دون إنترنت)
npm run e2e          # بعد preview: 71 فحصاً + لقطات شاشة بستة مقاسات
```

يتطلب Node.js 20 أو أحدث.

## 4. النشر على Vercel

المشروع مضبوط في `vercel.json` (إطار Vite، مخرجات `dist`، عدم تخزين `sw.js` مؤقتاً).

1. ادفع المستودع إلى GitHub.
2. في Vercel: Add New → Project → اختر المستودع → Deploy (لا حاجة لمتغيرات بيئة).
3. كل دفع إلى `main` ينشر إصداراً جديداً؛ الشاشات تحمّله في الخلفية وتطبقه **في وقت آمن** (لا أذان أو إقامة خلال 3 دقائق، وخارج الشاشة السوداء والأذكار).

## 5. تجهيز الجهاز للعمل دون إنترنت

1. افتح الرابط على التلفاز/الحاسوب **مع وجود إنترنت** وانتظر 10 ثوانٍ.
2. افتح الإعدادات ← «جدول المواقيت» ← استورد جدول الوزارة لولايتك.
3. اضبط اسم المسجد، الإقامة، الجمعة.
4. «التشخيص» ← تأكد أن «العمل دون إنترنت: جاهز».
5. أعد تحميل الصفحة مرة واحدة، ثم يمكن فصل الإنترنت.
6. نزّل نسخة احتياطية من «النسخ الاحتياطي» واحفظها.

## 7. اختصارات لوحة المفاتيح وجهاز التحكم

| المفتاح | الوظيفة |
|---|---|
| `Esc` / رجوع | إظهار/إخفاء الأزرار (لا يمكنه تجاوز خروج المتصفح من ملء الشاشة) |
| `F` | ملء الشاشة |
| `P` | تبديل وضع العرض (Kiosk) |
| `Shift + S` | فتح الإعدادات |
| `OK` / `Enter` / الأسهم | إظهار الأزرار 10 ثوانٍ |
| `OK` × 3 خلال ثانيتين | خروج طارئ من الشاشة السوداء/الأذكار الحالية (إن كان مفعّلاً) |
| نقرتان على الشاشة | إظهار الأزرار في وضع العرض |

## 8. قيود معروفة (بصراحة)

- المتصفح لا يستطيع **التشغيل التلقائي** عند تشغيل التلفاز ولا **ضمان العمل في الخلفية**؛ يحتاج ذلك إعداداً في الجهاز نفسه (راجع `docs/TV-SETUP.md`).
- ملء الشاشة يتطلب ضغطة من المستخدم، وبعض متصفحات التلفاز تمنعه.
- منع إطفاء الشاشة (Wake Lock) غير مدعوم في كل المتصفحات.
- لا يوجد تحميل آلي للجدول الرسمي لأن موقع الوزارة يمنع الوصول الآلي.
- إحداثيات الولايات تقريبية وتستخدم فقط للمواقيت المحسوبة.
- الحد الأدنى: Chrome 73+ / Safari 12.1+ (أجهزة التلفاز الأقدم قد لا تعمل).
